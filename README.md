<details>
<summary><h3>💻 Deploy on VPS / Localhost</h3></summary>

**1. Clone the repository**
```bash
git clone https://github.com/KIRU-OP/codex-music
cd codexMusic
```

**2. Install system dependencies**
```bash
sudo apt-get update -y
sudo apt-get upgrade -y
sudo apt-get install python3-pip ffmpeg -y
```

**3. Install Python requirements**
```bash
pip3 install -U -r requirements.txt
```

**4. Configure environment variables**
```bash
cp sample.env .env
nano .env   # Fill in API_ID, API_HASH, BOT_TOKEN, MONGO_DB_URI, etc.
```

**5. Start the bot**
```bash
python3 -m codex
```

**Or run it persistently in the background:**
```bash
tmux new-session -d -s codexMusic "bash start"
```
</details>

<details>
<summary><h3>🐳 Deploy with Docker</h3></summary>

```bash
git clone https://github.com/KIRU-OP/codex-music
cd codexMusic
cp sample.env .env   # fill in your credentials

docker build -t codexmusic .
docker run -d --env-file .env --name codexmusic codexmusic
```
</details>

<h2 align="center" id="-required-variables">🔑 Required Variables</h2>

<div align="center">

| Variable | Description |
|---|---|
| `API_ID` | Your Telegram API ID from [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | Your Telegram API Hash from [my.telegram.org](https://my.telegram.org) |
| `BOT_TOKEN` | Bot token from [@BotFather](https://t.me/BotFather) |
| `MONGO_DB_URI` | MongoDB connection URI ([MongoDB Atlas](https://www.mongodb.com/cloud/atlas)) |
| `OWNER_ID` | Your Telegram user ID (bot owner) |
| `STRING_SESSION` | Pyrogram string session for the assistant account |

</div>

> 📄 See `sample.env` in the repo for the full list of optional configuration variables.

<h2 align="center" id="-basic-commands">🎮 Basic Commands</h2>

<div align="center">

| Command | Description |
|---|---|
| `/play` | Play a song by name or reply to an audio file |
| `/vplay` | Play a video in the voice chat |
| `/pause` / `/resume` | Pause or resume playback |
| `/skip` | Skip the current track |
| `/end` | Stop playback and clear the queue |
| `/queue` | Show the current queue |
| `/shuffle` | Shuffle the queue |
| `/ping` | Check the bot's response time |

</div>

<h2 align="center" id="-faq">❓ FAQ</h2>

<details>
<summary><b>Bot voice chat mein join nahi ho raha, kya karu?</b></summary>
<br>
Make sure the assistant account (STRING_SESSION) is added as a member of the group/channel and that a voice chat is active before using <code>/play</code>.
</details>

<details>
<summary><b>Free hosting par bot sleep ho jaata hai?</b></summary>
<br>
codexMusic ships with a built-in keep-alive web server — pair it with an uptime pinger (like UptimeRobot) on Render/Heroku free tier to keep it awake.
</details>

<details>
<summary><b>Can I run multiple assistant accounts?</b></summary>
<br>
Yes — codexMusic supports multi-client load balancing so you can add several assistant string sessions for better scaling.
</details>
